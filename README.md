# İstanbul Gabari Envanteri — İnteraktif Harita

İstanbul genelindeki köprü ve alt geçitlerin düşey açıklık (gabari) envanterini
gösteren Folium/Leaflet tabanlı interaktif harita.

Yayın adresi (GitHub Pages etkinleştirildikten sonra):

https://darkeaglehome.github.io/istanbul-gabari-haritasi/

## Altlıklar

Yalnızca Esri servisleri kullanılır:

- Esri World Imagery (uydu)
- Esri World Street Map (cadde)
- Esri World Topo Map (topografik)
- Esri World Light Gray Canvas (sade yol haritası)
